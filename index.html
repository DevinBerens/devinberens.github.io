One quick setup step

To sync recipes across everyone's phones, add your free Firebase config near the top of index.html.

  1. Create a free project at console.firebase.google.com
  2. Add a Web app and copy its firebaseConfig
  3. Enable Cloud Firestore (start in test mode)
  4. Paste the config into the FIREBASE_CONFIG block in index.html and push

See README.md for the full walkthrough.
